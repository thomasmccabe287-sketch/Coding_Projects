# athletixDOCS

**An AI-powered injury tracking and documentation system for high school athletes.**

---

## Overview

athletixDOCS is a web application built to streamline how sports medicine staff and coaches track, log, and monitor injuries across a high school athletic program. Instead of relying on paper forms or disconnected spreadsheets, athletixDOCS centralizes athlete injury data in one place — making it easier to spot patterns, manage recovery timelines, and keep everyone informed.

The app was originally developed as a Sports Medicine class project at Central Catholic High School (San Antonio, TX) and is currently being prepared for real-world use across school sports programs in the upcoming season.

---

## Features

- **Injury Logging** — Record injury type, date, affected body part, and severity for individual athletes
- **Athlete Profiles** — Each athlete has a dedicated profile tracking their full injury history
- **Data Overview** — View injury trends across a team or sport at a glance
- **AI-Assisted Development** — Built using Base44, an AI-powered app development platform, enabling rapid prototyping and smart UI generation

---

## Tech Stack

| Tool | Purpose |
|------|---------|
| Base44 | AI-powered app builder / development platform |

---

## Why I Built This

High school sports medicine programs often track injuries informally — on paper, in binders, or not at all. This makes it hard to identify recurring issues, communicate between staff, or maintain accurate records over a season. athletixDOCS was designed to solve that problem with a simple, accessible tool that anyone on a sports staff can use without technical training.

## Projects

### Tideman
**Language:** C  
**Topic:** Algorithms, Graph Theory, Sorting

Implements the **Tideman voting algorithm** (also known as Ranked Pairs), a method for determining the winner of an election using ranked-choice ballots. The algorithm builds a graph of candidate matchups and locks in winning pairs without creating cycles — ensuring a fair, cycle-free outcome.

Key concepts applied:
- Pairwise comparison logic
- Cycle detection using recursive depth-first search (DFS)
- Sorting and ranking candidate pairs by margin of victory

---

### Runoff
**Language:** C  
**Topic:** Algorithms, Ranked-Choice Voting

Implements a **ranked-choice runoff election**, where voters rank candidates by preference. If no candidate wins a majority in the first round, the candidate with the fewest votes is eliminated and votes are redistributed — repeating until a winner emerges.

Key concepts applied:
- Multi-round elimination logic
- Voter preference arrays and tabulation
- Edge case handling (ties, exhausted ballots)
